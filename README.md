# 미미네 · 매장 운영 관리

최상위 `index.html`이 매출·비용 흐름 중심의 새 화면입니다. 서버에서는 기존 미미네 계정으로 로그인하고 활성 사용자 권한을 확인한 뒤 실제 장부·상품·입금 데이터를 읽습니다. 운영 데이터와 미리보기 데이터는 분리되어 있습니다.

- 저장·수정·삭제·촬영·스캔·입고·내보내기 등을 일관된 SVG 아이콘과 짧은 이름으로 표시.
- 기간 선택은 홈 기준 아이콘으로 통일. 매출·지출 입력은 금액 옆 저장 아이콘만 표시하며 접근성 이름을 유지.
- 지출은 항목 → 사용처/내용 → 금액 순서. 카드 대금 항목과 금액 클릭 시 전체 선택 지원. 입금 사업 필터는 실제 사업 로고와 전체·미분류 아이콘 사용.
- 홈·장부·비교·예측의 매출 금액을 눌러 오늘 매출 입력. 금액 옆 저장 버튼과 키보드 높이에 맞춘 입력창. 금액 입력칸을 누르면 기존 금액 전체 선택 후 바로 교체.
- 홈 금액을 눌러 매출·비용 등록, 기간 조회 및 작년/직전/직접 지정 비교.
- 부드러운 일별 곡선과 날짜 상세, 작년 일매출 비교, 기록 기반 월말 매출 추정.
- 우리은행 문자 수신 내역, 입금자명 자동 분류, 대상 제외, 월별·기간 합계.
- 상품 원가·수량·판매가·유통기한, 바코드 조회, 영수증 OCR 후 확인·일괄 입고.
- 상품·입고·가격·영수증·선택 비용은 한 DB 트랜잭션으로 저장하고 중복 요청을 차단합니다.

Node.js 22 이상에서 `npm ci`, `npm run build`, `npm test`를 실행합니다. `npm run preview`는 휴대폰 폭 검증 도구도 엽니다. 빌드는 버전이 고정된 npm 패키지에서 로그인/OCR/바코드 엔진을 준비하고 `dist`를 생성합니다. 최상위와 dist의 index는 같은 내용입니다.

파일 주소(file/content) 또는 `?preview=1`은 가상 데이터로 체험하며, 새로 열면 초기화됩니다. 실제 운영은 https://mimine-ramyeon.netlify.app/ 에서 로그인합니다. 기존 계정·사진·분류·수신폰 관리 화면은 `legacy/index.html`에 보존되어 있습니다.

입금은 은행 직접 조회가 아니라 하루온종일 수신폰의 문자 전달 경로입니다. 키오스크/POS 매출 자동 수집과 상품별 판매 자동 차감은 연결되지 않았습니다. 사진 OCR 결과는 저장 전에 확인·보정합니다.
