1. 실제 데이터로 수정본 실행하기

ZIP 전체를 먼저 압축 해제하세요. 실행 파일만 따로 꺼내지 마세요.
PC에 Node.js 22 이상이 필요합니다.

Windows: START-WINDOWS.cmd를 두 번 클릭합니다.
Mac/Linux: 압축을 푼 폴더에서 터미널로 node app-server.mjs를 실행합니다.
브라우저에서 http://localhost:4173/index.html 을 엽니다.
기존 미미네 계정으로 로그인하면 사용 승인 확인 후 실제 데이터를 읽습니다.
사용 중에는 실행 창을 열어 두세요. 종료는 실행 창에서 Ctrl+C입니다.

실행용 dist와 필요한 정적 파일을 포함했습니다. 단순 실행에는 npm install이 필요 없습니다.
이 서버는 현재 PC의 localhost에서만 열립니다. 외부에 공개하거나 배포하지 않습니다.
실데이터 화면에서 저장하면 기존 서버의 실제 장부에 반영됩니다.

2. index.html과 mockup.html 차이

index.html: 수정된 실제 로그인·장부 화면입니다. 최상위와 dist/index.html은 같습니다.
파일 앱에서 index.html을 직접 열면(file:// 또는 Android content://) 실데이터를 불러오지 않습니다.
위의 서버 실행 방법으로 접속해야 합니다. 운영 사이트 링크는 아직 수정 전 배포본입니다.
스마트폰 파일 앱에서 여는 것만으로 수정본의 실제 로그인·은행 연결은 실행되지 않습니다.

mockup.html: 별도의 가상 데이터 목업입니다. 화면만 빠르게 확인할 때 여세요.
실제 데이터에 연결하지 않으며 다시 열면 초기화됩니다. 목업의 카드사·결제일은 예시입니다.
로그인 없는 운영 진입이나 ?preview=1을 이용한 우회는 허용하지 않습니다.
실제 장부 원본과 로그인 비밀번호는 ZIP에 넣지 않았습니다.

3. 이번에 반영한 수정

- 작년 같은 기간과 비교: 빼기·등호를 제거하고 올해 매출, 작년 매출, 차이만 표시.
- 지출 항목: 임대료, 카드 대금, 상품매입, 소모품, 공과금, 기타 순서.
- 카드 대금 선택 시 사용처/내용 대신 카드사 선택. 기타 카드사는 직접 입력 가능.
- 홈 상단에 정기 납부 알림. 3초마다 롤링하며 다음·일시정지 버튼 제공.
- 납부 완료는 녹색, 예정·일부 납부는 주황색, 기한 지남은 빨간색으로 구분.
- 실제 비용 입력 내역에 따라 상태 계산. 비용을 입력하면 완료 상태에 반영.
- 임대료는 기존 비용 내역에서 최근 금액을 읽어 매월 1일 기본 알림 제공.
- 카드별 실제 결제일은 홈 알림의 설정 아이콘에서 한 번 등록.
- 주말·공휴일은 다음 영업일로 이동. 31일이 없는 달은 말일 기준.
- 2026·2027년 공휴일과 대체공휴일 반영. 추가 임시휴일 직접 등록 가능.
- 알림 상세에서 비용 입력 시 카드사·예상 금액·납부 월을 미리 채움.
- 설정은 기존 로그인 사용자 권한으로 서버에 저장. 새로운 DB 구조 변경 없음.
- 납부 완료는 비용 입력 기준이며 은행 자동이체 조회나 송금 실행이 아님.

기존의 기간별 비교, 12개월 분석, 그래프, 입력 편의, 상품 사진, 가로 넘침 방지,
하단 메뉴와 좌우 밀기, 입금 분류 및 상품 기능도 유지했습니다.

4. 소스와 검증

소스를 수정한 뒤 다시 빌드: npm ci → npm run build → npm test
실데이터 로컬 실행: npm start
휴대폰 폭 가상 미리보기 도구: npm run preview
