1. 화면 미리보기
ZIP 전체를 먼저 압축 해제한 뒤 가장 바깥쪽 index.html을 여세요.
파일 주소(file/content)로 열면 로그인 없이 가상 데이터 미리보기가 실행됩니다.
이 파일 미리보기는 운영 데이터에 연결하지 않으며 다시 열면 변경 내용이 초기화됩니다.
legacy/index.html은 기존 관리 화면이므로 이번 새 화면 확인은 최상위 index.html로 하세요.

2. 반영한 수정
- 작년 매출: 회색 실선. 범례도 회색 실선.
- 현재 매출: 녹색, 비용: 빨강, 증가: 파랑, 감소: 빨강.
- 일별 비교 표: 날짜 → 작년 매출 → 일매출 → 증감.
- 최근 7일: 오늘 포함 최근 7일 + 내일부터 7일, 총 14일.
- 이번 달·지난달: 1일부터 말일까지. 올해: 1월 1일~12월 31일.
- 직접 선택은 미래 날짜도 조회 가능.
- 미래 구간은 작년 매출 참고, 올해 금액은 예정 표시. 합계·증감은 오늘까지 실제 등록액 기준.
- 하단 메뉴 글자·아이콘 확대 및 안전 여백, 선택 메뉴 파란 배경.
- 기존 상품 사진 적용, 가로 넘침 방지, 좌우 밀기 메뉴 이동 유지.

3. 실제 데이터
수정본은 아직 배포하지 않았습니다. 현재 운영 사이트는 변경하지 않았습니다.
실제 데이터 기능은 서버에서 기존 계정으로 로그인한 상태로 사용합니다.
파일을 직접 연 가상 미리보기에서는 실제 로그인·은행 수신·운영 저장을 확인할 수 없습니다.
영수증 OCR·바코드 카메라 등은 로컬 서버 또는 HTTPS 환경에서 확인하세요.

4. 소스와 빌드
Node.js 22 이상: npm ci → npm run build → npm test
휴대폰 폭 미리보기 도구: npm run preview
최상위 index.html과 dist/index.html은 같은 수정 화면입니다.
dist에는 실행에 필요한 정적 파일을, flow에는 수정 소스를 포함했습니다.
운영 설정과 마이그레이션은 기존 파일 그대로 보존되어 있습니다.
