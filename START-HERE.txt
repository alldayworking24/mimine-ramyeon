1. 화면 미리보기
ZIP 전체를 먼저 압축 해제하세요.
index.html: 로그인 진입 화면입니다. 파일로 열면 운영 사이트에서 로그인하도록 안내합니다.
mockup.html: 별도의 가상 데이터 목업입니다. 실제 데이터에 연결하지 않으며 다시 열면 초기화됩니다.
운영 로그인 화면에서 목업으로 들어가는 버튼은 제거했고 ?preview=1도 로그인 검사를 건너뛰지 않습니다.
legacy/index.html은 기존 관리 화면입니다.

2. 반영한 수정
- 홈 일별 흐름 위에 올해 매출 − 작년 매출 = 차이와 누적 비교 그래프 추가.
- 매출·비용·차이 숫자 앞의 '기간' 문구 제거. 작년 일매출 목록 위에는 표시된 날짜의 합계 표시.
- 비교·예측을 12개월 분석 화면으로 분리. 월별 매출·비용·차이와 작년/증감, 연간 합계, 월별 그래프 제공.
- 비교·예측의 작년은 1월 1일~12월 31일 전체. 올해의 미래는 예정, 진행 중인 달은 오늘까지 실제 기록.
- 월·그래프 클릭 → 월 합계/일별 비교 → 날짜 클릭 시 상세. 예측과 비용 항목 합계는 비교·예측에서 확인.
- index는 로그인과 서버 사용자 확인·사용 승인을 거쳐야 실제 데이터 조회 가능.
- 로그아웃·계정 변경 시 기존 화면을 즉시 감추고 로그인으로 이동. 가상 목업은 별도 파일로 분리.
- 전체 기간 선택을 홈 아이콘으로 통일. 입금의 최근 7일도 같은 아이콘 사용.
- 매출·지출 저장 버튼은 금액 바로 옆 아이콘만 표시. 클릭 안내와 접근성 이름 유지.
- 지출 입력 순서: 지출일 → 항목 → 사용처/내용 → 금액. 카드 대금 항목 추가.
- 지출 금액도 클릭하면 기존 금액 전체 선택. 금액·합계에서 오늘 지출 입력 가능.
- 입금 사업 선택: 전체(격자), 미미네·하루온종일(기존 로고), 미분류(물음표 보관함). 버튼 글자 없이 구분.
- 매출 금액 입력칸을 누르면 기존 금액 전체 선택. 지우지 않고 바로 새 금액 입력.
- 주요 버튼을 의미에 맞는 SVG 아이콘 + 짧은 이름으로 통일.
- 장부·비교·예측 등의 매출 금액을 누르면 오늘 매출 바로 입력.
- 금액 입력칸 바로 옆 저장 버튼, 키보드 높이에 맞춘 입력창, 정산·메모 접기.
- 작년 매출: 회색 실선. 범례도 회색 실선.
- 현재 매출: 녹색, 비용: 빨강, 증가: 파랑, 감소: 빨강.
- 일별 비교 표: 날짜 → 작년 매출 → 일매출 → 증감.
- 최근 7일: 오늘 포함 최근 7일 + 내일부터 7일, 총 14일.
- 이번 달·지난달: 1일부터 말일까지. 올해: 1월 1일~12월 31일.
- 직접 선택은 미래 날짜도 조회 가능.
- 미래 구간은 작년 매출 참고, 올해 금액은 예정 표시. 합계·증감은 오늘까지 실제 등록액 기준.
- 하단 메뉴 글자·아이콘 확대 및 안전 여백, 선택 메뉴 파란 배경.
- 기존 상품 사진 적용, 가로 넘침 방지, 좌우 밀기 메뉴 이동 유지.

3. 실제 데이터
수정본은 아직 배포하지 않았습니다. 현재 운영 사이트는 변경하지 않았습니다.
실제 데이터 기능은 서버에서 기존 계정으로 로그인한 상태로 사용합니다.
파일을 직접 연 가상 미리보기에서는 실제 로그인·은행 수신·운영 저장을 확인할 수 없습니다.
영수증 OCR·바코드 카메라 등은 로컬 서버 또는 HTTPS 환경에서 확인하세요.

4. 소스와 빌드
Node.js 22 이상: npm ci → npm run build → npm test
휴대폰 폭 미리보기 도구: npm run preview
최상위 index.html과 dist/index.html은 같은 수정 화면입니다.
dist에는 실행에 필요한 정적 파일을, flow에는 수정 소스를 포함했습니다.
운영 설정과 마이그레이션은 기존 파일 그대로 보존되어 있습니다.
